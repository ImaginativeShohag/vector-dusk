Make a dark palette. Reuse it.

1. Import

Drop SVG or Android VectorDrawable XML files into the editor, or choose Paste XML. For Android resource colors, also import your light-mode colors.xml.

2. Adjust

Select a palette row or click a shape. Choose a replacement with the picker, hex input, or generated tints and shades. The 5 / 10 / 20 selector changes the number of swatches; transparency is preserved.

Apply changes to the shared palette, this illustration, or a selected fill, stroke or gradient stop. Individual overrides take priority. Keep original protects a color; Reset override removes the current override. Undo and Redo reverse edits.

Eight-digit hex uses #RRGGBBAA for SVG and #AARRGGBB for Android. The editor labels the format.

3. Save

  • Save profile: shared colors in this browser. Export profile downloads a portable copy.
  • Save workspace: downloads artwork, palette and individual overrides. Use Import JSON to reopen either file.

Save a workspace before closing or reloading. Profiles do not save artwork.

4. Export

Export one SVG/XML or a collection ZIP. Place Android files in res/drawable-night/ using the original filenames.

Work with an agent

Choose Copy prompt for agent and paste the instructions into your agent chat. The agent opens your SVG or Android VectorDrawable XML in the editor. Review the import notes, adjust the artwork, then tell the agent when you are finished.

An agent with browser access can return to the same tab and get the current export using View XML or Download. The prompt does not grant browser access. If the agent cannot access that tab, download the result and give it the file. For Android resource references, also import your light-mode colors.xml.

Import links use #v=1&name=illustration.svg&encoding=gzip&data=…. The full link can contain up to 65,536 characters; decompressed artwork can contain up to 5,000,000 bytes. Use Paste XML or Import vectors if the link is too large.

A link contains the artwork and is not encrypted. Anyone with the link can read it. After importing, the editor clears the fragment from the address bar. Save a workspace before refreshing or closing the tab.

Know the limits

Use static SVG; expand symbols and use instances first. Scripts, external resources and unsupported effects are removed. Review import notes. Android tint, trim paths and sweep gradients have preview limitations; verify exports on Android.

Limits: 5 MB per vector, 100 illustrations and 50 MB per workspace JSON. Use a current desktop browser. Check the final colors and contrast yourself.
