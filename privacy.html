Vector Dusk
Editor · Guide · Privacy

Your artwork stays in your browser.

Vector Dusk is a free browser tool with no account, upload endpoint, analytics, ads, or third-party runtime scripts. Editing, previewing and exporting happen on your device.

What is stored?

When you choose Save profile, the browser stores your palette name, shared color mappings, imported resource colors and preview background using local storage. It also remembers the last selected profile. These values are scoped to this website’s origin. A saved profile that cannot be read is skipped and left in storage unchanged; Delete removes a profile you no longer need.

Artwork and illustration-specific edits stay in the open page’s memory. They are not automatically saved. Save workspace downloads a JSON backup containing the original artwork and your edits. Exported SVG, XML, ZIP and JSON files are saved through your browser’s download feature.

How to remove local data

Use your browser’s site settings to clear storage for this site. That removes saved profiles; export any profiles you want to keep first. Close the editor to release in-memory artwork. Remove downloaded files using your computer’s normal file controls.

Hosting and network requests

Your browser requests this website’s HTML, JavaScript, styles and sample files from the hosting provider. The host may receive ordinary access information such as your IP address and browser information. Imported artwork and palettes are not sent with these requests. If deployed on GitHub Pages, GitHub’s privacy practices apply to that hosting traffic.

GitHub privacy statement

Review imported files

SVG imports remove active content and external references, but some unsupported visual features are also removed. Read the import notes and check your exported artwork before distributing it. Workspace backups retain the original input files.
